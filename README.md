# 🏎️📊 Análise Exploratória da Fórmula 1 (1950–2024)

Este repositório apresenta uma **Análise Exploratória de Dados (EDA)** completa da Fórmula 1, abrangendo todas as temporadas de **1950 a 2024**.  
O projeto busca identificar padrões, tendências, eras dominantes, evolução de desempenho e comportamento histórico de pilotos e construtores ao longo de mais de 70 anos de competições.

---

## 📁 Base de Dados

Os dados utilizados vêm do dataset oficial do Kaggle:

**Formula 1 World Championship (1950–2024)**

A base contém:

- 🏁 Resultados de corridas  
- 🧑‍✈️ Pilotos  
- 🏢 Construtores  
- 🌍 Circuitos  
- ⏱️ Dados de classificação (Qualifying)  
- 🏎️ Voltas e telemetria básica  
- ⚙️ Status, eventos e motivos de abandono  

---

## 🧰 Tecnologias Utilizadas

- Python 3  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Plotly  
- Kaggle API  
- Jupyter Notebook
